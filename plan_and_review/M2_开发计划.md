## 二、模块化开发策略

**原则**：实现一个模块 → 编写测试 → 测试通过 → 再进行下一个模块

### 关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 认证方案 | **纯 JWT** | 无状态、易扩展、Phase 4 简化 |
| 密码加密 | **OpenSSL PBKDF2** | Rocky 9 自带，0 依赖风险 |
| 连接池超时 | **3 秒超时** | 防止并发场景死锁 |

class DBPool {
private:
    std::queue<MYSQL*> _pool;
    std::mutex _mtx;
    std::condition_variable _cv;  // 条件变量，支持超时等待
    std::string _host, _user, _password, _db;
    int _port, _pool_size;

public:
    void init(const Config& cfg);
    
    // 获取连接（超时返回 nullptr，单位毫秒）
    MYSQL* get_connection(int timeout_ms = 3000);
    
    // 归还连接
    void return_connection(MYSQL* conn);
    
    ~DBPool();  // 关闭所有连接
};
```

**关键点**：
- 使用 `std::condition_variable::wait_for()` 实现超时
- 并发测试：N 线程请求，池大小 M（N > M），验证无死锁

namespace gobang {
namespace security {

// PBKDF2 密码加密（OpenSSL）
std::string pbkdf2_hash(const std::string& password);

bool pbkdf2_verify(const std::string& password, const std::string& hash);

std::string jwt_generate(int64_t user_id, int64_t expire_sec = 3600 * 24);

} // namespace security
} // namespace gobang
```

## 四、数据库表结构

### user 表
```sql
CREATE TABLE user (
    id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(32) UNIQUE NOT NULL COMMENT '用户名',
    password_hash VARCHAR(128) NOT NULL COMMENT 'PBKDF2 密码哈希',
    score INT UNSIGNED DEFAULT 1500 COMMENT '天梯分数',
    total_count INT UNSIGNED DEFAULT 0 COMMENT '总场次',
    win_count INT UNSIGNED DEFAULT 0 COMMENT '胜场',
    status TINYINT DEFAULT 0 COMMENT '0-离线 1-大厅 2-房间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_score (score),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> **注**：如需账号封禁功能，可添加 `is_banned TINYINT DEFAULT 0` 字段（M3 再考虑）
